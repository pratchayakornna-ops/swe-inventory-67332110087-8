# SWE Inventory Management System

**Repository:** `swe-inventory-67332110087-8`  
**รหัสนักศึกษา:** `67332110087-8`  
**วิชา:** Software Engineering in AI Era  

ระบบจัดการคลังสินค้า (Inventory Management System) รองรับทั้งสินค้าที่จับต้องได้ (Physical Goods) และสินค้าดิจิทัล (Digital Goods/Files) พร้อมชุดงาน Lab 04: UX, Code Review และ Evidence-based Debugging

## โครงสร้างโปรเจกต์
- `inventory.py`: คลาสหลัก `Inventory` และ `InventoryItem`
- `lab04-ai-coding-ux/`: งานทั้งหมดของ Lab 04
  - `findings-lab04.md`: ผลสัมภาษณ์และ Point of View
  - `persona.md`: Persona และ Journey Map 5 ขั้น
  - `accessibility-review.md`: การตรวจ WCAG AA และจุดที่ AI พลาด
  - `prompt-vs-context.md`: เปรียบเทียบ Prompt Engineering กับ Context Engineering
  - `code-review.md`: รายงาน Review PR โมดูล `inventory_service.py`
  - `debug-log.md`: บันทึกการ Debug ตามหลักฐาน 5 ขั้นตอน
  - `discount.py`: โมดูลคำนวณส่วนลดที่แก้ไขตาม Root Cause แล้ว (ผ่าน Test 100%)
  - `reflection-and-exercises.md`: คำตอบแบบฝึกหัดส่งท้าย 4 ข้อ
  - `assets/`: Wireframe ASCII 3 หน้า และ Mockup Diagram (`.drawio`)
